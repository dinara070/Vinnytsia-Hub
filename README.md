# Vinnytsia-Hub

### Головні технічні особливості
- Session State (Керування станом): Проєкт активно використовує пам'ять сесії для збереження даних під час переходів між сторінками. У ній зберігаються: обрані пам'ятки (favorites), історія повідомлень чат-бота (chat_history), залишені відгуки (feedback_list) та поточна сторінка навігації.
- База даних у коді: Вся інформація (пам'ятки, ресторани, події, словник для бота) зберігається у вигляді структурованих списків та словників (JSON-подібна структура), що робить код легким для розгортання без зовнішньої БД.
- Бокова панель навігації: Використовується стандартний st.sidebar для перемикання між 10 різними розділами застосунку.

### Огляд ключових розділів (Сторінок)
1. Головна сторінка (🏠)
- Зустрічає користувача градієнтним банером.
- Містить статистику міста, швидкі кнопки для переходу в інші розділи, цікаві факти та демонстраційний графік популярності пам'яток (побудований через st.bar_chart та Pandas).

2. Каталог пам'яток та Обране (🗺️ / ⭐)
- Пам'ятки: Детальний список локацій із системою пошуку за текстом та фільтрацією за категоріями (Музеї, Парки, Релігія тощо).
- Обране: Користувач може натиснути кнопку «Додати в обране», і локація збережеться у пам'яті застосунку. На окремій сторінці «Обране» формується персональний список (який потім використовується для маршруту).

3. Інтерактивна карта (🧭)
- Використовує вбудовану функцію st.map. Завдяки наявності точних координат (широта і довгота) для кожної пам'ятки, застосунок генерує карту з відмітками. Точки на карті динамічно змінюються залежно від обраної категорії.

4. Розумний планувальник маршруту (📝)
- Кілер-фіча проєкту. Користувач обирає пам'ятки (за замовчуванням підтягуються ті, що в «Обраному»), вказує час початку прогулянки та орієнтовний час на переміщення між локаціями.
- Скрипт вираховує загальний час (додаючи тривалість візиту кожної локації та час на дорогу) і генерує погодинний розклад дня.
- Готовий маршрут можна миттєво завантажити як .txt файл (через st.download_button).

5. Віртуальний гід / Чат-бот (🤖)
- Вбудований чат-інтерфейс (st.chat_message, st.chat_input), який імітує спілкування зі штучним інтелектом.
- Працює на основі Rule-based логіки (база знань на основі ключових слів). Скрипт аналізує запит користувача, шукає збіги за ключовими словами (наприклад, "фонтан", "поїсти", "готель") і видає заготовлену, найбільш релевантну відповідь.
- Є блок швидких запитань-підказок.

6. Довідкові розділи (🎉 Події, 🍽️ Ресторани, ℹ️ Про місто)
- Структурована подача інформації з використанням колонок, карток-контейнерів (st.container) та вкладок (st.tabs).
- Ресторани можна динамічно сортувати за рейтингом або за алфавітом.

7. Зворотний зв'язок (📮)

Форма (st.form) для збору відгуків від користувачів. Відгуки проходять базову валідацію (чи не порожні обов'язкові поля) і одразу публікуються на цій же сторінці, імітуючи роботу з базою даних.
